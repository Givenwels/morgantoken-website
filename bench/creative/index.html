02 / TASK

题目与判断维度

创建一个 HTML，内容是 SVG 绘制一个鹈鹕骑自行车的 2D 动画。

  • 骑行动画与连续性：踏板转动时双脚跟随，车轮转动与前进相符，动作循环没有明显跳变、错位或抖动。
  • 骑乘空间关系：鹈鹕坐在车座上，翅膀够到车把，双脚靠近并跟随踏板，而非站在车旁或悬空。
  • 主体完整性：能辨认鹈鹕的长喙、身体和翅膀，也能辨认车轮、车架、车把、座椅和踏板。
  • 视觉质量：构图、配色与运动的可读性；画面精美不能弥补骑行动作缺失。
  • 运行有效性：HTML 能打开，SVG 能显示并持续播放；不能运行的作品无法完成题目。

  2. 2 级 · 动作优势双方都有骑行动作；胜方的脚、踏板、车轮与身体联动明显更连贯。

02 / TASK

题目与判断维度

创建独立 index.html，使用 JavaScript 和 Canvas 实现实时物理模拟。正六边形恒速旋转，小球在内部受重力并与边界碰撞。小球始终在六边形内部；反弹应考虑旋转边界的局部速度并有适当能量损耗；运动连续。自动运行，无需操作，适配窗口。

  • 碰撞检测：接触边界才反弹，不穿墙、不逃逸，也不在顶点处卡死。
  • 物理合理性：重力、能量损耗和旋转边界的局部速度在运动结果中可见。
  • 几何与旋转：六边形形状稳定并匀速旋转。
  • 动画与运行：运动连续，页面自动运行并适配窗口。

本题先看

02 / TASK

题目与判断维度

创建独立 index.html，可从 CDN 加载 Three.js。三个依次啮合的机械齿轮，齿数为 12、24、36，模数与齿距一致、固定轴安装且厚度合理。第一齿轮恒速旋转，后两齿轮按齿数比反向联动，齿轮不明显穿透或分离。金属材质、柔和灯光、阴影、缓慢环绕相机，自动播放。

CIDER POND 秋日湖泊

单文件 HTML Three.js · 30 秒 · 困难+

本题先看

湖面生态是否活起来：鸭群沿平滑路径游动，尾流扩散消散，并与落叶和水面发生可见交互。

02 / TASK

题目与判断维度

实现明亮十月午后的秋季森林湖泊，树木为红枫、金色桦/颤杨、锈色橡树等落叶乔木，不得出现针叶树或常绿树；湖面为主要亮部且反射树木，暖光和薄雾，树干枝杈清晰、树冠多层不规则；芦苇、睡莲、木码头与小桥、苔藓原木、石径与长椅、蘑菇、苍鹭、蜻蜓。一只母鸭带小鸭，另有绿头雄鸭与一只白鸭，鸭群沿平滑路径游弋，在水面上形成扩散消散的 V 形尾流，并有觅食、梳羽、轻微碰撞溅水；落叶飘落后漂浮、被鸭群推开。高三分之四视角的电影式相机在约 25–30 秒内推近与绕行，随后拉远重复；不出现天空直视。加入顶部和底部模糊、湖面中间清晰的 tilt-shift 后处理；轻微增强饱和度对比度；明亮温暖童话微缩风格，禁止黑色阴影、阴郁噪点、明显低多边形和彩色玻璃感。仅以代码几何和材质建模，禁止外部模型及图像热链接；全屏响应、自动运行、持续稳定，目标 60fps。

  • 动态行为：鸭群、尾流、觅食、梳羽、溅水和落叶交互可见，不能只有整体平移。
  • 场景要素：落叶森林、亮湖面、木码头、小桥、植物与动物符合题面。
  • 程序化建模：树冠、树干和各物体有层次，不依赖外部模型与图片。
  • 画面、镜头与运行：温暖明亮；镜头推近绕行，移轴清晰；页面持续稳定运行。
