AUTOMATION / WHAT RUNS

自动化具体发生在哪里

视频 GSB 可直接在网页操作；创意编程运行由本地工作台处理。

环节系统现在能做什么人的参与
视频素材与配对元数据自动整理读取公开题目、模型和媒体链接，核对同一实例的提示词与参考图，检查外链后组成对比，不下载视频副本。抽查素材是否对题，在线观看并记录 GSB 与现象备注
题库建设自动整理与检查输入主题或 TXT / MD / DOCX 资料，导出 Agent 出题包，或配置 API 生成候选题；系统检查结构与重复。审核发布后冻结题面、GSB 指南和采证计划。编辑候选，核对资料、通过条件与规则，确认后发布
模型答题配置后自动已接 API 批次生成，记录原文、实际模型、耗时和 token；也能上传 Agent 作品。填自己的 API，选题与模型后启动
运行与采证自动生成作品入队，隔离运行，截图、录屏并检查证据完整性。处理失败或异常运行
匿名配对自动API 批次内按同题、版本、参数与运行条件配对；Agent 作品按已记录的平台和配置配对。补齐缺少对照的作品
GSB 与人机协同人工判断系统计算已有人工票与独立 AI 票的一致率，只列分歧；AI 票目前需导入。同屏观看、四档 GSB、复核分歧
报告自动统计视频页按已保存人票汇总模型胜负、同好同差与任务表现，汇集备注，导出报告或 AI 总结资料包。结论撰写 API 待接入。补充现象和时间点，核对统计与备注，审核结论后再发布

题库工厂已支持出题包、候选导入、自动检查和人工审核发布；API 出题与模型作答通道均已具备，真实模型 API 尚未配置。API 视觉评审仍未接入。GSB 由人判断，机器参考票独立保存。

展示口径　视频页统计你当前浏览器保存或导入的评分，不是全站访客榜单。AI 总结先支持资料包导出，模型 API 尚未配置。创意编程目前只有鹈鹕有真实作品与成绩；意图识别展示流程。
