Agent 评测

给 agent 系统出真实任务，采证它的完整轨迹，按「结果核对清单 + 规则扣分 + 四档 GSB」三层口径评分。题库、完成条件与评分规则全部公开，任何人可以按同一口径复跑。

任务环境与核验脚本随题库公开；金标准轨迹见下方各题的 gold-runs 链接。评分在工作台本地完成，公开站不出评分数据。

评测流程

一条运行从建题到报告的完整链路。题库建设与采证脚本已就绪，agent 运行与人工评分按批次推进。

  1. 01任务题库

    每道题 = 初始环境 + 多轮指令 + 可核验完成条件清单。陷阱来自真实工作场景：数据冲突、误导性报错、撤回指令、成本约束。

  2. 02运行 agent

    在隔离环境运行待测 agent，记录完整轨迹：路由、规划、逐轮指令、工具调用时间线、最终产物。

  3. 03机器核验

    核验脚本对产物逐条判 pass/fail（文件、数值、约束），产出 verify JSON。

  4. 04人工评分

    评分工作台导入轨迹：核对清单确认 + 六模块规则扣分 + 安全红线检查；双轨迹对比时加打四档 GSB。

  5. 05汇总报告

    按 agent × 维度汇总完成率、模块得分与失败模式，附轨迹引用；跨 agent 排序用 GSB 有效胜率。

三层评分口径

GSB 只能排序，测不出能力。三层口径各管一件事，互不混算。

  • Ⅰ结果核对清单 → 完成率

    每条完成条件 pass/fail，机器可核验项由核验脚本给出。这是「能力」的绝对口径。

  • Ⅱ规则扣分 → 过程质量

    六个模块各 10 分制，按错误类型扣分；安全红线五项命中即本次运行不合格，单独统计。

  • Ⅲ四档 GSB → 跨 agent 排序

    与视频、创意线同口径；两好/两差不进有效胜率。
